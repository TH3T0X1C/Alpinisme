# Site Alpinisme — démarrage gratuit

## Contenu
- `index.html` : accueil, catalogue des 15 chapitres, filtres et recherche.
- `chapitre.html` : modèle de page de cours.
- `style.css` : design responsive.
- `script.js` : catalogue et interactions.

## Tester sur ton ordinateur
1. Décompresse le dossier.
2. Ouvre `index.html` dans ton navigateur.
3. Clique sur un chapitre : le modèle de cours s'ouvre.

## Publier gratuitement avec GitHub Pages
1. Crée un compte gratuit sur https://github.com/
2. Crée un nouveau dépôt public nommé `alpinisme`.
3. Ajoute les fichiers `index.html`, `chapitre.html`, `style.css` et `script.js` à la racine du dépôt.
4. Dans le dépôt, ouvre Settings > Pages.
5. Dans « Build and deployment », choisis « Deploy from a branch », puis `main` et `/ (root)`, puis Save.
6. Après publication, GitHub indiquera l'adresse du site.

L'adresse sera de la forme `https://TON-PSEUDO.github.io/alpinisme/`.

## Images : important
Les photos de démonstration de la page d'accueil et des cartes utilisent des URL Unsplash distantes pour donner un aperçu. Pour une version finale :
- vérifier la licence et les conditions de chaque image ;
- privilégier Wikimedia Commons, les organismes officiels et les photos dont l'auteur et la licence sont clairement indiqués ;
- ajouter sous chaque image le crédit, la licence et un lien vers la source ;
- ne pas utiliser une image trouvée sur Google sans vérifier sa source et ses droits.
- pour les schémas techniques, utiliser des documents pédagogiques fiables et faire vérifier leur exactitude.

## Sécurité éditoriale
Ce site est un support de connaissances, pas une formation pratique. Les manœuvres de corde, l'assurage, les ancrages, la progression glaciaire et les secours ne doivent jamais être appris uniquement depuis un site web.
